# Trillionnium World Security Contracts

- `trnm-world-threat-model-v1.md` — assets, trust boundaries, threat cases, and required mitigations;
- `trnm-world-service-identity-secrets-v1.md` — role audiences, secret storage, signer custody, rotation, revocation, and break-glass.

Security status remains evidence-class specific. Source controls do not grant
KMS/HSM, mTLS, public-edge, custody, fraud, privacy, or commercial approval.

Security reports should follow the root `SECURITY.md` disclosure process once
published; never include live credentials, private keys, personal data, or
exploit details in public issue bodies.
