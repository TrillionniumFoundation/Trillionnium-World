# Playtest Evidence

This tree contains playtest forms, packets, and observations.

Automated tests and rendered smoke captures cannot substitute for real human evidence. Do not pre-fill participant identity, comprehension, accessibility, usability, or multiplayer observations.

Every completed packet records consented identity through an approved private process, exact build commit/artifact digest, hardware/display/input mode/session length, predefined tasks and success criteria, raw observations/failures/follow-up issues, and whether the participant is a developer or previously trained on the flow.

Uncompleted templates must remain explicitly marked `pending`.
