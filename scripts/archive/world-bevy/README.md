# Frozen World/Bevy Script Surface

These scripts belonged to the superseded `trnm-world-bevy`, S5/S6, OpenRA,
Android, public-release, or large evidence-packet routes. They are preserved as
historical implementation evidence and are not supported from this location.

The only current player runner is:

```bash
scripts/run_trnm_first_contact.sh
```

The compatibility name `scripts/run_trillionnium_world_bevy_client.sh` remains
at the repository root and delegates to that runner. Do not add new product
checks to this archive.
